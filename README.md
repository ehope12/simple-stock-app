# simple-stock-app

An app for users to view stock price data and overviews of a variety of companies/ETFs.

## Getting Started

### Dependencies

* Python
* Dash
* Dash_mantime_components
* Dash_bootstrap_components
* Dash_bootstrap_templates
* Yfinance
* Plotly

### Usage

Once you have all of the listed dependencies, clone the repo. Then run the Python script:
```
python simple_stock_app.py
```

Follow the instructions in the shell to view the app.

Use the text box to type a company/ETF's ticker and scroll to see all relevant information. Use the buttons to select a time range for the data.
